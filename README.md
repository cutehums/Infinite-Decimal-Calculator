Infinite Number Calculator
C 언어로 작성된 큰 정수 및 유한 자릿수 소수 연산 계산기 프로젝트입니다. 숫자의 각 자릿수를 연결 리스트에 저장해 일반적인 기본 정수형의 자릿수 제한을 넘는 계산을 구현하려는 프로젝트입니다.
현재 상태: 개발 및 디버깅 필요
소스에 메모리 관리 및 연산 흐름 문제가 있어 실행 오류나 잘못된 계산 결과가 발생할 수 있습니다. 기존 calculator.exe가 정상 동작한다는 보장은 없습니다. 또한 이름과 달리 무한 반복소수의 정확한 표현이나 나눗셈은 구현되어 있지 않습니다.

프로젝트 구성
.
├── calculator.c       # 스택·연결 리스트·입력 처리·후위 표기 변환·곱셈
├── calculator.h       # 자료구조 및 함수 선언
├── callculatorMain.c  # main 함수, 사용자 확인 및 연산 실행
├── plus.c             # 덧셈
├── minus.c            # 뺄셈
├── input.txt          # 계산할 수식
└── calculator.exe     # 제공된 Windows 실행 파일
실행 방법 (Windows)
1. 모든 파일을 같은 폴더에 둡니다.
2. input.txt를 열어 수식을 한 줄로 작성하고 저장합니다. 예:
   123+456
3. 해당 폴더에서 PowerShell을 열고 실행합니다.
   .\calculator.exe
4. 프로그램이 파일에서 읽은 수식을 확인하면 Y를 입력하고 Enter를 눌러 계산을 시도합니다. N은 계산을 진행하지 않습니다.
입력은 콘솔이 아닌 input.txt에서 읽습니다. 파일 이름과 현재 작업 디렉터리가 일치해야 합니다. 첫 테스트는 간단한 덧셈부터 시작하세요.

소스에서 빌드하기
GCC(MinGW-w64 등)가 설치되어 있다면 프로젝트 폴더에서 다음 명령을 실행할 수 있습니다.
gcc -fcommon -Wall -Wextra callculatorMain.c calculator.c plus.c minus.c -o calculator.exe
이후:
.\calculator.exe
-fcommon은 calculator.h의 int size; 정의가 여러 소스 파일에 포함되는 문제를 임시로 우회하기 위한 옵션입니다. 근본적으로는 헤더를 extern int size;로 변경하고 한 .c 파일에만 int size = 0;을 정의해야 합니다. 컴파일에 성공하더라도 실행 및 계산 정확성을 보장하지 않습니다.

현재 입력 검사 코드가 주로 숫자, ., +, -, *, 괄호를 대상으로 하므로, 처음에는 양의 정수 덧셈 같은 단순 수식을 권장합니다. 여러 연산자가 섞인 식, 음수, 소수 및 괄호는 오류가 발생할 수 있습니다.
내부 동작 개요
1. fileRead()가 input.txt에서 수식을 읽습니다.
2. infix2postfix()가 중위 표기식을 후위 표기식으로 변환합니다.
3. Dlist_maker()가 숫자들을 연결 리스트로 구성해 스택에 저장합니다.
4. callculatorMain.c에서 연산자를 읽고 list_add(), minus(), multiply()를 호출합니다.
5. Printer()가 결과 연결 리스트의 자릿수를 출력합니다.
알려진 문제 및 개선 과제
- makeLS()의 할당 크기가 sizeof(LStack*)이고 반환문이 누락되어 있습니다.
- fileRead()의 문자열 버퍼 및 종료 문자 처리가 안전하지 않으며 파일 열기 실패 검사가 없습니다.
- 메인 루프가 빈 연산자 스택에 pop()을 시도할 수 있습니다.
- 곱셈 구현에 잘못된 포인터 접근과 부적절한 메모리 해제 위험이 있습니다.
- 뺄셈에서 피연산자 순서와 음수 처리의 정확성을 확인해야 합니다.
- 입력 검증, 연산 우선순위, 자릿수 올림/내림 및 메모리 해제에 대한 테스트가 필요합니다.
테스트 권장 사항
버그를 수정한 뒤 1+2, 999+1, 1000-1, 12*34, 1.2+3.45, 2*(3+4) 등으로 테스트하고 예상값과 비교하세요. 이 예제들은 테스트용 수식이며 현재 버전에서 정상 동작한다고 검증된 입력은 아닙니다.
